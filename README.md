## 一、ZgoCloud 退款政策的「三道红线」

先说结论：ZgoCloud **支持退款**，但它不是「无理由随便退」的那种。官方在服务条款里写得明明白白，退款得同时满足下面三个硬性条件，缺一条都不行。

**红线一：3 天退款窗口**

购买产品超过 3 天，不予退款。注意这个 3 天是从付款成功开始算的，不是从机器开通开始算——预售产品例外，预售的退款时限从机器实际开通时间起算。所以如果你买的是现货，付款那一刻倒计时就开始走了，别想着「机器还没装好我不着急」。

**红线二：流量不超过 10GB**

流量使用量超过 10GB（上下行合计，in + out），不予退款。10GB 听起来不少，但你装个系统、跑个测速、再 scp 传几个文件，很快就过去了。想退款的话，到手之后别急着折腾，先想清楚要不要留。

**红线三：每账户最多退 2 次**

同一账户累计退款不能超过两次，超过之后哪怕你完全符合其他条件，也不退了。这条的意思很明确：商家不欢迎「专业试错型」买家。如果你打算反复买反复退薅测试鸡，这条路在 ZgoCloud 走不通。

## 二、12 种「直接不予退款」的情况逐条拆解

光看上面三条还不够。ZgoCloud 在 ToS 里列了一长串「不予退款」的兜底情形，我把它们整理成下面这张表，方便你一条条对照：

| 编号 | 不予退款的情形 | 通俗解释 |
| --- | --- | --- |
| 1 | 同一账户多次退款（超 2 次） | 退款次数用完了 |
| 2 | 流量使用量超过 10GB | 上下行加起来超 10G 就别想了 |
| 3 | 接受其他客户转移的产品 | Push 过来的机器不能退 |
| 4 | 购买超过 3 天 | 时间窗口已过 |
| 5 | 产品说明明确标注不可退款 | 主要是特价套餐，下面单说 |
| 6 | 因网络问题 | 「网速慢」不构成退款理由 |
| 7 | 因任何类型的滥用造成损失 | 你违规用了出事，自己扛 |
| 8 | 以（D）DoS 攻击为目标 | 被打还不给你退，挺扎心 |
| 9 | IP 地理位置原因 | 想要日本 IP 结果定位在别处？不退 |
| 10 | IP 被封或列入黑名单（含 GFW、blocklist.de 等） | IP 被墙了不退，但有 3 小时换 IP 窗口 |
| 11 | 续订服务 | 续费一律不退 |
| 12 | 充值金额 | 账户里充的钱不退 |

这里面最容易踩坑的是第 6 条和第 10 条。

第 6 条「网络问题不退款」听着挺霸道，但 VPS 圈普遍都这么干——网络是个动态的东西，今天好明天差，要是允许因为网速退款，商家一天到晚处理退款就行了。所以下单前一定先看测试 IP，自己实测延迟和丢包，别买完才发现你家宽带到这个机房就是慢。

第 10 条更狠：IP 被 GFW 墙了，不退。但是 ZgoCloud 给了一个「3 小时黄金窗口」——购买后如果发现 IP 有问题，3 小时内可以发工单申请免费换 IP，超过 3 小时就默认 IP 没问题，再想换就得花钱了。

## 三、特价套餐（Special Offer）为什么不支持退款

这是新手最容易翻车的地方。

ZgoCloud 在官网 Special Offer 页面明确写着一句话：**「No refunds / money back on those plans.」** 也就是说，Special Offer 系列（也就是大家说的「特价鸡」「年付促销款」）从一开始就不在退款范围内，不管你买完是不是 3 秒钟、流量是不是 0KB，都不退。

为什么？因为特价套餐本身就是亏本或者贴本冲规模的，商家指望的是你留下来长期续费，而不是买完就退。如果你买特价套餐的目的是「先试一下不行就退」，那趁早别买——这条路在 ZgoCloud 是堵死的。

我见过不少人买完特价鸡发现线路不合适，去工单申请退款被拒，然后在论坛吐槽「ZgoCloud 不退款」。其实不是人家不退款，是你买的那个套餐本来就不退。**下单之前在商品页找一找有没有「non-refundable」「不可退款」这类字样，看到就心里有数了。**

> **一句话原则**：特价套餐价格香，但等于一锤子买卖，买定离手。

## 四、IP 被墙了怎么办：3 小时换 IP 黄金窗口

IP 被墙是国内 VPS 用户的「宿命级问题」。ZgoCloud 对这件事有一套独立的政策，和退款政策是分开的，但两者会互相影响。

**新购机器**：买完一开机发现 IP 就是被墙的，3 小时内发工单可以免费换。超过 3 小时，IP 视为正常，再想换得花钱。

**使用过程中 IP 被墙**：在「确保有可用 IP」的前提下可以付费更换，普通 IPv4 每次 $6，ISP/IP 属性 IP 每次 $10。每个 VPS 最多申请换 3 次 IP，每月最多换 1 次，只适用于 IPv4。

这条政策直接决定了你退款会不会成功：如果你买了机器用了一周发现 IP 被墙，去申请退款会被第 10 条挡掉（IP 被封不退）；去申请免费换 IP 又超过了 3 小时窗口，只能花 $6 换。所以最稳的操作是——**到手立刻测 IP，有问题立刻发工单，别拖。**

## 五、ZgoCloud 退款流程实操：四步走完

确认自己符合退款条件之后，退款流程其实很简单，全程在工单系统里完成。ZgoCloud 支持中文工单，直接用中文沟通就行。

1. **登录客户后台**，左侧菜单找到「Support Tickets」。
2. **点击「Create new」** 新建一个工单。
3. **部门选择「Billing」**，主题写「退款申请」，正文描述退款理由。理由写得真诚一点、具体一点，比如「线路实测不达预期，延迟稳定在 280ms 以上，不适合我的使用场景」，比「不想要了」通过率高。
4. **提交后等 24 小时内回复**。客服如果需要补充信息会继续在工单里问，记得及时回。符合条件的话，款项会原路退回（支持 PayPal、信用卡等支付方式，所以也走原路退）。

有个小细节：之前有用户反馈 ZgoCloud 工单响应挺快，活动款也能原路退款成功——但前提是你买的是支持退款的套餐，且符合那三条红线。

## 七、想避免退款纠纷？购买前的避坑清单

退款是兜底，不是策略。最好的退款是「不需要退款」。下面这几条做到了，能帮你把后续扯皮的概率降到最低。

**注册环节：别开代理、别瞎填信息**

ZgoCloud 开了反欺诈系统，注册时不要挂 VPN / 代理。地址、电话、IP 三者国家要对得上——比如你 IP 在中国，就老老实实选中国，地址写学校、公园这种公共地址也行，电话填格式正确的中国手机号。乱写「姓名 AAA、地址 BBB」基本会被判欺诈，订单直接被拒，连退款的机会都没有。

**下单前：先 ping 测试 IP**

ZgoCloud 公开了各机房的测试 IP：
- 日本大阪：`45.87.95.5`
- 德国法尔肯施泰因：`194.36.27.3`
- 美国洛杉矶：`23.165.248.7`

下单之前先在你常用的网络环境下 ping 一下、跑个 traceroute，看看延迟和丢包。觉得能接受再下单，比买完再退省事一万倍。

**到手后：3 小时内测 IP**

## 九、常见问题 FAQ

**Q1：ZgoCloud 有「无理由退款」吗？**

**Q2：续费的订单能退吗？**

不能。续订服务一律不退款，这条 ToS 里写得清清楚楚。所以续费之前一定确认这台机器你真的要继续用。

**Q3：账户里充的余额能退吗？**

不能。充值金额不可退款。所以别一次性充太多钱进去「图方便」，按需充值就好。

**Q4：我买的特价套餐实在不想要了，能退吗？**

不能。Special Offer 系列在购买页面就明确标注了 non-refundable，这是商家明确约定的不退款情形，发工单也会被拒。买特价套餐之前一定想清楚。

**Q5：IP 被墙了能作为退款理由吗？**

不能。IP 被封或列入黑名单属于第 10 条不予退款情形。但你有两条出路：3 小时内免费换 IP，或之后花 $6 / $10 付费换 IP（每个 VPS 最多换 3 次，每月最多 1 次）。

**Q6：退款多久到账？**

工单提交后通常 24 小时内有回复，符合条件的话款项会原路退回（PayPal、信用卡支付的走原路）。具体到账时间取决于支付渠道，PayPal 一般几个工作日内。

**Q7：从别人那 Push 过来的机器能退吗？**

不能。接受其他客户转移的产品不在退款范围内。Push 服务本身还要收 $10/台的手续费，所以别人转给你的机器，到手就不能退了。

**Q8：切换数据中心之后能退吗？**

不能。ZgoCloud 收取 $10/次的数据中心切换费，且服务转移后不再提供退款。所以换机房之前想清楚。
